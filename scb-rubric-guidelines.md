# SCB v2.0 - Rubric Guidelines (0 / 3 / 5 Anchors)

This file defines the three-anchor method for SCB scoring.

- 0 = severe failure, missing signal, or veto-level condition
- 3 = baseline publishable quality
- 5 = best-practice competitive execution

Scores 1, 2, and 4 are interpolated between these anchors by reviewer judgment or AI scoring logic.

---

## Global Interpolation Rule

| Score | Interpretation |
|-------|----------------|
| 1 | Closer to 0 than 3; major remediation required |
| 2 | Closer to 3 than 0; partially complete baseline |
| 4 | Closer to 5 than 3; strong implementation with minor gaps |
